# 鲸鱼娘 1.0.1

蓝紫色鲸尾少女的 Windows 桌面陪伴。轻点人物即可聊天，拖拽可移动位置；透明区域允许鼠标穿透。

## 开始使用

运行 `Whale-Girl-1.0.1-Setup.exe` 完成安装，再打开“鲸鱼娘”。右键人物选择“设置”，填写自己的 DeepSeek API Key 并保存，即可在桌面聊天。天气和时间问答可以直接使用，天气城市可在设置里修改。

- 单击人物展开或收起聊天框，同时切换为闭眼笑形象 0.8 秒。
- DeepSeek 生成回答期间保持闭眼笑形象，结束后恢复睁眼形象。
- 聊天框右上角的小箭头可循环切换“紧凑、标准、宽大”三种布局。
- 右键人物可打开设置、隐藏人物或退出；隐藏后可从系统托盘再次打开。
- 设置支持昵称、人物大小、始终置顶、开机启动、主动陪伴与语音朗读。
- 右下角拖动到边界后会停止，主体保持可见，不再允许半身出屏；重启和保存人物大小时会自动修正越界位置。

启用主动陪伴后，每分钟轮换一句问候，共 23 句。晚上 23:00 至次日 08:00 暂停主动问候，正在生成回答时也会暂缓。

## 界面设置

界面使用与人物一致的蓝紫色。设置中的“不透明度”可分别调整各部分，数值越高越清晰，越低越透明。

| 项目 | 默认不透明度 |
| --- | ---: |
| 人物 | 100% |
| 对话框 | 80% |
| 消息气泡 | 88% |
| 输入框 | 92% |
| 文字 | 100% |
| 问候气泡 | 50% |

调整后点击“保存设置”，下次打开时继续使用。

## 对话记录

每次提交的问答会追加到同一份 `对话积累.md`，按本地日期和提问时间分组，保留完整回答及其中的 Markdown。时间、天气问答和请求失败提示也会保存。新对话或清空聊天不会删除文件历史。

首次使用的默认位置是 Windows“文档”文件夹下的 `对话积累` 文件夹。升级时会保留已经设置的保存目录。

在设置的“对话保存目录”中，可以粘贴文件夹地址，或点击“选择”浏览文件夹，再点击“保存设置”。“打开”可查看当前保存目录。更换目录后，新问答写入新位置，原有记录仍保留在旧目录。

## 数据与存储

- 对话模型为 DeepSeek V4 Flash，支持联网搜索及可选思考强度；应用不额外截断模型回答。
- API Key 使用 Windows 加密保存，聊天内容发送至 DeepSeek；天气城市发送至 Open-Meteo。
- 应用设置和加密密钥保存在当前 Windows 用户的 `%APPDATA%\whale-girl` 文件夹中。
- 对话记录保存在用户选择的目录中，与应用安装目录分开。
- 本仓库不包含个人设置、密钥或对话记录。

源码存放于私人仓库 [nkmz-kazuki/whale-girl](https://github.com/nkmz-kazuki/whale-girl)。

## 本地运行与构建

在 Windows 上安装 Node.js 与 npm 后，在项目目录执行：

```powershell
npm ci
npm start
```

运行测试与生成安装包：

```powershell
npm test
node scripts/verify-ui.cjs
npm run dist
```

安装包输出到 `dist/Whale-Girl-1.0.1-Setup.exe`。测试使用独立临时目录，覆盖对话追加、长文本、日期分组、并发写入、保存目录切换、设置校验、问候轮换和屏幕边界。界面检查使用模拟聊天，不读取个人设置或调用外部服务，结果保存在 `dist/ui-check/`。

项目目录：

- `src/`：桌宠界面、聊天、设置和对话记录。
- `assets/`：两张人物立绘和应用图标。
- `tests/`：自动化测试。
- `scripts/`：构建辅助工具。
- `dist/`：本地构建产物，不纳入源码仓库。
